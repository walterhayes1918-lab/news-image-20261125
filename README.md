## Files

- `main.py` — the entrypoint. A standard-library-only Python 3.13 program (os and shutil, nothing else): it copies `entry.png` from this repository to `$MAKEFUN_OUTPUT_DIR/entry.png`, or `/output/entry.png` when that variable is unset. No network, no clock, no randomness, so both grader runs write identical bytes.
- `entry.png` — the image itself: a 1024×1024 newspaper front page, "THE WORLD IN ONE PAGE", for Wednesday 25 November 2026, 122,009 bytes.
